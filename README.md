# PRIMEWARE | Coming Soon Landing Page

This is the official **Coming Soon** landing page for **PRIMEWARE**, a high-end digital transformation and product engineering agency. As a subsidiary of **HOUSEFIX.LK (PVT) LTD**, PRIMEWARE focuses on architecting premium digital experiences and scalable software solutions.

## 🌟 Key Features
- **Ultra-Minimalist Aesthetic**: A sophisticated, dark-themed interface designed to project engineering excellence and modern minimalism.
- **Pure CSS Background Dynamics**: Implements high-performance radial gradients and floating "glow" effects using CSS keyframe animations—zero external dependencies.
- **Fluid Typography**: Uses the 'Outfit' typeface with responsive sizing to ensure a perfect reading experience across all device classes.
- **Glassmorphic CTA**: Features a subtle, backdrop-filtered call-to-action button with high-end hover states and box-shadow dynamics.
- **Synchronised Animations**: Orchestrated entrance animations (FadeInUp/FadeInDown) to create a polished, "living" interface upon page load.

## 🛠️ Technical Stack
- **Core**: Semantic HTML5 and Vanilla CSS3 (Single-file architecture).
- **Animations**: CSS Variables and custom Keyframe orchestration for high-performance rendering.
- **Typography**: [Google Fonts](https://fonts.google.com/) (Outfit).
- **Design System**: Atomic CSS principles within a unified internal stylesheet.

## 📁 Repository Structure
- `index.html`: Contains both the semantic markup and the entire design system (CSS).
- `CNAME`: Configured for deployment on custom subdomains.

## 🚀 Deployment
This project is a static website and can be deployed instantly to GitHub Pages, Vercel, Netlify, or any standard web server.
